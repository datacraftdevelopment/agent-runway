# Inbox: loose ideas, not yet shaped

One line per item. Dated, sourced, in client-safe words. No status, no
progress: this is not a task list. A line leaves this file by becoming a
brainstorm (and so a design doc in `docs/specs/`), by merging into something
that already exists, or by being retired with a reason in the session entry.

Format: `- YYYY-MM-DD · <source> · <the idea, one line>`
