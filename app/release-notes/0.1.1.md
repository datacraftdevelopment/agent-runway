- First launch walks you through setup: what Runway does, what it found on this Mac, what it will install before it installs it, and the first prompt to paste into your agent.
- On later launches Runway checks again and only shows the walkthrough if something is missing.
- What's New: this screen. It shows after an update, and "What's New…" in the menu opens it again.
- `runway doctor` checks without creating anything; `runway init` makes Runway's folder and database.
- A real app icon: a paper plane taking off, with a matching paper plane in the menu bar.
- Install from a disk image: drag Runway into Applications. If you open it from Downloads or the disk image, it offers to move itself there, since updates only work from Applications.
- The Agent Runway plugin carries every skill its workflow uses (new: map, grill, prototype and spec), so you install nothing else.
