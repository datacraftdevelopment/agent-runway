### Do this after updating
- In What's New, click **Update the skills**. It asks first, then updates Agent Runway in Claude Code and Codex.
- Restart any Claude Code or Codex sessions you have open, so they pick up the new skills.

### New
- Hands-on tickets. When you file work, the parts that need you (a device, the simulator, how it feels) become hands-on tickets. Runway never starts them. They show as "Hands-on · yours", with Copy prompt and Mark done.
- The Agent Runway plugin goes to 0.3.0, with 15 skills: the new `hands-on` skill, and six build skills from Superpowers (writing-plans, executing-plans, subagent-driven-development, test-driven-development, systematic-debugging, verification-before-completion).
- `file-tickets` sorts work into Runway tickets and hands-on ones, and asks for checks a reviewer can run.

### Fixed
- A long question or review no longer pushes the toolbar off the window. The ticket panel scrolls.
- The function reviewer can now run the experiment a check asks for (change a value, see a test fail), in a throwaway copy.
- Swift and iOS builds run under Codex: it may write Xcode's and SwiftPM's caches, without a looser sandbox.
