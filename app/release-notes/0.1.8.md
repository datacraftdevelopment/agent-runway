- A very long question or review in the ticket panel no longer pushes the toolbar and stats off the window. The panel scrolls on its own, and long text shows its first lines with "Show all".
- The function reviewer may now run the experiments an Acceptance line asks for, such as changing a threshold to see a test fail, in its own throwaway copy. It undoes each one and never commits or pushes. The code reviewer still only reads.
- The file-tickets and spec skills now ask for Acceptance lines a reviewer can check on its own, from the repo.
- Swift and iOS builds can run under Codex: each run gets its own temp and module cache, and Codex may write Xcode's and SwiftPM's cache folders, without loosening its sandbox.
- Hands-on tickets: when you file work, the parts that need you (a device, the simulator, how it feels) are marked hands-on. Runway never starts them. On the board they're "Hands-on · yours", with the prompt to copy and Mark done. Tickets that wait on one say so, and a ticket you finished yourself shows "Done by hand".
- The Agent Runway plugin now carries 15 skills, including hands-on, test-driven development, systematic debugging, writing and running plans, and checking work before calling it done. What's New offers "Update the skills" so Claude Code and Codex get them.
