### Do this after updating
- Nothing to click: the skills update themselves to 0.3.1 in Claude Code and Codex. Restart your Claude Code or Codex sessions to load them.
- The skills leave repos that aren't in Runway alone now. No tickets, no asking: the work just gets built in the session. In a Runway repo they ask once, after the spec, and only when the work is a good fit: "Run this through the Runway app, or do it here?"

### New
- One prompt per ticket. Right-click or the inspector: **Work on this in Claude Code or Codex**. The session reads the ticket and its last run and talks it through. It takes the ticket back only to change code, and it always tells Runway how it ended (an answer, give back, done, drop, or a note).
- `runway note T-n "..."` leaves a note on a ticket when a session only talked it over.
- A taken-back ticket shows how long it's been yours and when its worktree last changed: "Taken back by you · 40 min · last activity 5 min ago".

### Fixed
- Hands-off counts what you didn't have to do yourself. Answering a question or clicking Merge still counts as hands-off. Taking a ticket back or merging outside Runway doesn't.
